# Research notes (sources behind the plan)

Checked online on 21 Nov 2026. Items marked **VERIFY** could not be confirmed and must be settled before the related feature is locked.

| Topic | Finding | Used in the plan as |
|---|---|---|
| DHIS2 demo data | Demo databases (including Sierra Leone) are published at [databases.dhis2.org](https://databases.dhis2.org) and restore with `psql` or Docker ([DHIS2 in Docker](https://developers.dhis2.org/docs/tutorials/dhis2-docker)). Sierra Leone moved weekly IDSR reporting for 26 diseases to DHIS2 ([CDC EID](https://wwwnc.cdc.gov/eid/article/28/13/pdfs/22-0711.pdf)). | Primary aggregate source. **VERIFY** the demo DB contains weekly disease data; no licence terms found. |
| DHIS2 tracker model | Tracked entity → enrollment → events → data values ([data model](https://docs.dhis2.org/en/topics/training-docs/tracker-use-academy/tracker-data-model/tracker-data-model-session-summary.html)). | Shape of the case layer: Person → Case → Encounter / Lab / Vaccination / CaseEvent. |
| Case-based surveillance fields | WHO measles standards list unique ID, geography, date of birth, onset, notification, investigation and specimen dates, and classification (suspected, clinically compatible, laboratory-confirmed, epidemiologically linked, discarded) ([WHO](https://www.who.int/publications/m/item/vaccine-preventable-diseases-surveillance-standards-measles)). | Fields of `cases`. **VERIFY** the full set against the standards and the [AFRO guidelines](https://afro.who.int/sites/default/files/2017-06/who-african-regional-measles-and-rubella-surveillance-guidelines_updated-draft-version-april-2015.pdf). |
| Synthea | Synthetic patients as FHIR R4 JSON; custom diseases are JSON state machines ([FHIR wiki](https://github.com/synthetichealth/synthea/wiki/HL7-FHIR), [customizing](https://mitre.github.io/fhir-for-research/modules/synthea-customizing)). | Optional. **VERIFY** measles, cholera and malaria modules exist. The plan's own generator does not depend on it. |
| Case reporting standard | FHIR eCR IG (US Realm, R4, v2.1.2) defines the eICR and Reportability Response ([eCR](https://hl7.org/fhir/us/ecr)). | Notification API accepts a simplified FHIR Bundle, described as "informed by eCR". **VERIFY** profile names before claiming conformance. |
| Aggregate FHIR | `MeasureReport` has a summary level; HL7 publishes a [PublicHealthMeasureReport profile](https://hl7.org/fhir/uv/saner/StructureDefinition-PublicHealthMeasureReport.html). | Read-only indicator endpoint. |
| Real-time | Laravel's first-party route is Reverb with Echo (needs `pusher-js`); broadcasting runs on queued jobs; Mercure (SSE) is the alternative ([Broadcasting 13.x](https://laravel.com/framework/docs/13.x/broadcasting)). | Reverb + Echo with polling fallback; a queue worker and a Reverb process are needed in deployment. |
| Forecasting | Simple exponential smoothing is a strong short-horizon baseline with residual-based intervals; truncate counts at zero; use a moving average as baseline ([ILI preprint](https://www.medrxiv.org/content/10.1101/2022.10.27.22281617.full.pdf), [Petropoulos et al.](https://pubmed.ncbi.nlm.nih.gov/33311822/), [mpox study](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC12668862/)). The ILI evidence is a preprint; no single benchmark protocol for surveillance counts was found. | 1–4 week projections with intervals, backtested against a naive baseline. |
| Outbreak detection | EARS C1–C3 use short baselines; Farrington needs a year of data ([EARS/Farrington](https://pmc.ncbi.nlm.nih.gov/articles/PMC3320440), [CDC MMWR](https://www.cdc.gov/mmwr/preview/mmwrhtml/su5401a20.htm)). The u-chart is the Shewhart chart for rates with varying population. | Short-baseline alert rule; u-chart for display. |
| Small numbers | Practice varies: suppress below 10 (Arkansas, Washington), reliability rule below 5 (Oregon), exceptions for communicable-disease reporting (Illinois) ([Oregon](https://www.oregon.gov/oha/PH/DISEASESCONDITIONS/COMMUNICABLEDISEASE/Documents/Guidelines-for-Reporting-Small-Numbers-to-Protect-Confidentiality-March-2015.pdf), [Arkansas](https://healthy.arkansas.gov/wp-content/uploads/ADH-Small-Numbers-Standards-Final-March.2025.pdf)). | Flag counts below 5. |
| Alert fatigue | Severity tiering, role tailoring, threshold adjustment and suppression reduce overrides; suppression carries safety risk ([2023 review](https://pmc.ncbi.nlm.nih.gov/articles/PMC10654862), [AHRQ](https://psnet.ahrq.gov/primer/alert-fatigue)). No direct evidence on digests was found. | Tiers, scope targeting, cooldown, count floor, escalation; digest is a design choice. |
| WCAG 2.2 | New AA criteria: 2.4.11 Focus Not Obscured (Minimum), 2.5.7 Dragging Movements, 2.5.8 Target Size (Minimum), 3.3.8 Accessible Authentication (Minimum); 4.1.1 removed ([W3C](https://w3.org/WAI/standards-guidelines/wcag/new-in-22/)). No chart-specific criterion. | Quality requirements and front-end hardening. |
| HSTS | Laravel emits HSTS only when it sees the request as secure ([StackHawk](https://stackhawk.com/blog/laravel-http-strict-transport-security-guide-what-it-is-and-how-to-enable-it)). | Set in the Apache vhost in production; skip on local `.test`. |
| Geometry | Sierra Leone boundaries on [HDX](https://data.humdata.org/dataset/sierra-leone-all-ad-min-level-boundaries); sources disagree on district count (14 vs 16). | **VERIFY** names against imported org units. |
| Other sources | [WHO GHO API](https://who.int/data/gho/info/gho-odata-api), [WHO provisional measles](https://immunizationdata.who.int/global/wiise-detail-page/measles-reported-cases-and-incidence), [CDC NNDSS weekly](https://catalog.data.gov/dataset/nndss-weekly-data) (ODbL), [Wikimedia pageviews](https://doc.wikimedia.org/generated-data-platform/aqs/analytics-api/documentation/access-policy.html) (descriptive User-Agent, new 2026 rate limits). | Reference, fallback and web-metric sources. **VERIFY** the GHO endpoint and licence. Page views are global per language, not by country. |
